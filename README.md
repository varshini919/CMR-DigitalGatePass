# CMR Digital Gate Pass

A React-based web application for managing digital gate pass requests through a simple and responsive user interface.

## Features

- Digital gate pass request
- Student profile section
- Notification section
- Responsive user interface
- Reusable React components

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Lucide React
- Git
- GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/varshini919/CMR-DigitalGatePass.git
```

Go to the project folder:

```bash
cd CMR-DigitalGatePass
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
